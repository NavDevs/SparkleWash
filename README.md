# Sparkle Wash

Sparkle Wash is India's premier door-to-door vehicle washing and servicing solution. Founded in 2020, we aim to make vehicle care convenient, affordable, and eco-friendly for every vehicle owner in India.

## 🚗 About the Project

Sparkle Wash is a comprehensive vehicle maintenance platform that brings professional cleaning and servicing right to your doorstep. Our mission is to save you time and effort while ensuring your vehicle stays spotless using eco-friendly products and water-saving techniques.

### Key Features

- Door-to-door service across major Indian cities
- Comprehensive care for all types of vehicles - cars, bikes, scooters, and more
- Eco-friendly cleaning solutions that are gentle on your vehicle
- Trained and verified professionals
- Transparent pricing with no hidden charges
- Easy online booking and payment options
- Real-time tracking of services
- Customer feedback and rating system

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Routing**: React Router DOM
- **State Management**: React Hooks
- **Data Fetching**: TanStack Query
- **Icons**: Lucide React
- **Forms**: React Hook Form
- **Validation**: Zod
- **Date Handling**: date-fns
- **Responsive Design**: Mobile-first approach

## 📋 Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

## 🚀 Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/sparkle-wash.git
   ```

2. Navigate to the project directory:
   ```bash
   cd sparkle-wash
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:8080`

## 🔧 Available Scripts

In the project directory, you can run:

- `npm run dev` - Runs the app in development mode
- `npm run build` - Builds the app for production
- `npm run preview` - Locally preview the production build
- `npm run lint` - Lints the codebase
