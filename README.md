# Sparkle Wash

A student project: a door-to-door vehicle cleaning service web app. Users can book car or bike washes at their home using a clean, responsive interface.

🔗 **Live Demo**: [https://sparkle-washer.netlify.app](https://sparkle-washer.netlify.app)

## 🛠️ Tech Stack
- **Frontend**: React + TypeScript  
- **Build Tool**: Vite  
- **Styling**: Tailwind CSS + shadcn/ui  
- **Routing**: React Router DOM  
- **State & Data**: React Hooks + TanStack Query (mocked data)  
- **Forms**: React Hook Form + Zod validation  
- **Utils**: date-fns, Lucide React icons  

## 📋 How to Run Locally
1. `git clone https://github.com/yourusername/sparkle-wash.git`  
2. `cd sparkle-wash`  
3. `npm install`  
4. `npm run dev` → opens at `http://localhost:8080`

## 📁 Key Pages
- Home, About, Services, Pricing  
- Booking → Confirmation flow  
- Orders, Profile, Login  

> Note: This is a frontend-only academic project. All data is simulated.
